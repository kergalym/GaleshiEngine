Tutorial 6

Material scripts: one recipe, many slots

Create a small JSON recipe that overrides material properties without replacing the slot's textures and apply it across a model.

In this tutorial

  • What a .mat file does
  • Create the recipe
  • Format and operators
  • Apply it in the editor
  • Supported properties
  • Save/load behavior

1. What a .mat file does

A .mat file is a JSON recipe that tunes properties of a material slot. Applying a recipe creates a material instance: the slot keeps its original material as the instance base, and only the properties listed in the recipe are changed.

The same recipe can be applied to different slots, so one master can drive many meshes. Textures are inherited from the base material and are never changed by the recipe.

2. Create the recipe

  1. Right-click in the Content Browser and choose Create Script Templates → Master Material (.mat).
  2. Open the generated file in the Code Editor or any text editor.
  3. Set a readable name and list the properties you want to change.
  4. Save the file. Use Reapply Master later after editing it. 
{
  "name": "Rough painted metal",
  "properties": {
    "metallicFactor": { "set": 1.0 },
    "roughnessFactor": { "add": 0.12 },
    "albedoFactor": { "mul": [0.82, 0.86, 0.92, 1.0] },
    "emissiveFactor": { "set": [0.0, 0.0, 0.0] }
  }
}

3. Format and operators

A plain number, array, or boolean is shorthand for set. An object with an operator key is also accepted, for example { "mul": 0.5 } or { "op": "mul", "value": 0.5 }.

OperatorMeaning
setReplace the value.
add / subAdd or subtract component-wise.
mul / divMultiply or divide component-wise.
min / maxComponent-wise minimum or maximum.
clampClamp to [min, max]; the value is a two-element array.

Scalars apply to one component. Vector values may have one, three, or four components; a one-component value broadcasts to every component. Booleans support set only.

4. Apply it in the editor

  1. Drag the .mat file from the Content Browser onto a material slot in Details. The slot becomes an instance and its listed properties are tuned.
  2. For a multi-material mesh or model, use Apply to All Slots to instance the recipe on every material slot in its hierarchy.
  3. Use Reapply Master after editing the .mat file.
  4. Use Clear Master to return to the instance base material.

The recipe changes material properties, not texture assignments. If a slot looks unchanged, check that the property you are editing is actually visible for that material type.

5. Supported properties

Scalars

metallicFactor, specularFactor, roughnessFactor, normalStrength, occlusionStrength, alphaCutoff, glassOpacity, subsurfaceStrength, subsurfaceRadius, translucencyOpacity, translucencyStrength, translucencyThickness, translucencyDistortion, translucencyShadowDepth, shadowDepthOffset, landscapeUvScale, landscapeDetailScale, landscapeDetailStrength, landscapeNormalStrength.

Colors and vectors

albedoFactor, emissiveFactor, subsurfaceColor, translucencyColor.

Booleans

isGlass, twoSided, backfaceCulling, alphaTest, alphaBlend, subsurfaceEnabled, translucencyEnabled, castsShadow.

6. Save/load behavior

The active recipe path is stored with the scene material table, so it survives save/load. The assigned values are serialized as well. Editing the .mat file later does not automatically change already instanced slots; use Reapply Master to pick up the new recipe.
