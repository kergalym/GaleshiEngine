Tutorial 5

Cloth painting and simulation

Paint a soft-body region directly on an existing mesh, tune its material, and see it simulated by Jolt in the editor and Play mode.

In this tutorial

  • How cloth is stored
  • Paint cloth
  • Cloth properties
  • Paint, clear, rebuild

1. How cloth is stored

Cloth is not a separate entity. It is a SoftBodyComponent added to an existing static or skeletal mesh entity. The entity keeps its mesh, material, transform, and hierarchy; only the painted vertices acquire cloth simulation.

Painted vertices are dynamic, unpainted vertices stay pinned. Only faces containing at least one painted vertex are added to the Jolt soft body.

2. Paint cloth

  1. Select an entity with a MeshComponent, or a static/skeletal model root, in the Outliner or viewport. A model root uses its first descendant mesh.
  2. Open Details → Cloth Painting.
  3. Enable the Painting cloth checkbox. This creates the soft-body component if it does not exist.
  4. Paint on the mesh with the left mouse button.
  5. Hold Alt while painting to erase.
  6. Release the mouse button. The editor rebuilds the Jolt soft-body body from the painted vertices.

Painted vertices are shown as small green crosses while the mesh is selected. The brush uses Brush Radius and Brush Strength from the Landscape sculpting controls.

Disabling Painting cloth only leaves paint mode. The painted weights and the cloth body remain on the mesh.

Dynamic and kinematic physics proxies do not expose the cloth tabs. Select the mesh or the model root, not the collider child.

3. Cloth properties

After painting is enabled, the Cloth Properties section exposes the simulation parameters:

ParameterDefaultMeaning
Mass1.0Per-vertex mass for dynamic vertices.
Friction0.5Jolt soft-body friction.
Restitution0.0Collision bounce.
Gravity Factor1.0Multiplier for world gravity.
Linear Damping0.1Per-vertex velocity damping.
Pressure0.0Jolt soft-body pressure.
Stiffness0.8Scales stretch, shear, and bend compliance.
Stretch Compliance1e-4Edge stretch softness.
Shear Compliance1e-4Shear softness.
Bend Compliance1e-3Bending softness.

Changing a value does not mutate the running Jolt body. Press Rebuild With Properties to recreate it with the new values.

5. Simulation and saved data

  • Cloth uses Jolt soft bodies.
  • Duplicate vertices at UV and normal seams are welded by position for simulation, then mapped back to the render mesh.
  • UpdateSoftBodies() copies simulated positions back into the mesh and recomputes normals every frame.
  • Simulation runs in both the editor and Play mode. Soft-body updates run after skeletal animation, so cloth on a skinned mesh is not immediately overwritten by the animation.

SoftBodyComponent is serialized with the entity and stores the paint weights, mass, friction, restitution, gravity factor, damping, pressure, and compliance values. The Jolt body id is runtime-only; a mesh with paint weights but no runtime body is rebuilt automatically when Play starts.

6. Limitations

  • Paint before starting simulation. Repainting an already deformed mesh uses the deformed vertices as the new rest pose.
  • Non-uniform entity scale is not baked into the soft body. Keep cloth meshes at a uniform scale where possible.
  • Tearing, wind forces, and self-collision controls are not exposed.
  • Cloth painted on an animated skeletal mesh drives the simulated region from the cloth simulation; that region no longer follows the skeletal animation.
  • A multi-mesh model or skeletal root authors cloth on its first descendant mesh.
  • Dense meshes produce large paint-weight arrays. Use them carefully.
