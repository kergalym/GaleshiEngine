Before you start

  • Build or install the editor. A local debug build is enough: 
    cmake --preset debug --fresh
cmake --build build/debug --target GaleshiEditor -j"$(nproc)"
cd build/debug/bin
./GaleshiEditor
  • Open a project from the Project Manager, or load an existing scene with Ctrl+O.
  • Keep the Output Log panel visible. Script and engine errors appear there.
